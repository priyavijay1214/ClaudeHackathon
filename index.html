How it works

Subtitles for social subtext

EchoConnect sits invisibly over your video call, reads the room every 4 seconds, and surfaces one calm nudge at a time.

01
Launch overlay
One click from menu bar. Selects active window.
02
Silent capture
Screenshot every 4s. Only sent when content changes.
03
Claude analyzes
Vision + structured reasoning. 1–2s latency target.
04
Nudge appears
One calm sentence. Color-coded by tone.
05
Auto-dismiss
Fades after 12s. Pin or expand to see reasoning.

Features

Built for real use, not demos

🧠
Claude Vision analysis
Multimodal AI reads facial expressions, body language, and context in real time.
💬
Floating nudge overlay
Always-on-top transparent window. Never blocks your call.
⚡
Change detection
Pixel diff skips API calls when nothing meaningful has changed. Saves cost and latency.
🔕
Quiet mode
Cmd+Shift+E to pause analysis instantly. No disruption when you need focus.
📍
Pin & expand
Click any nudge to pin it and read Claude's full reasoning in 1–2 sentences.
🔒
Zero storage
Screenshots sent to API and immediately discarded. Never written to disk.
Privacy

Nothing is stored. Ever.

For a tool built on trust, privacy isn't a feature — it's the foundation.

Privacy architecture

Screenshots sent directly to Anthropic API and immediately discarded — never written to disk
API key lives exclusively in the Electron main process — the UI never has access to it
No audio is ever recorded or analyzed
No account required — runs entirely on your machine with your own key
Nudges below 60% confidence are suppressed — we'd rather say nothing than mislead
